Cloudflare를 쓰고 Cloudflare에 도메인이 있다면 이걸 비교적 쉽게 해결할 수 있다. Tunnel이 동적인 public endpoint 구성을 도와주기 때문이다.

## 쿠버에 cloudflared 세팅하기

cloudflare가 Tunnel을 연결하려면 전용 데몬인 cloudflared를 세팅해줘야 한다.  
먼저 방금 받아온 토큰을 시크릿으로 넣어준다.  

```javascript
kubectl create secret generic cloudflared-token \
  --from-literal=token="YOUR_COPIED_CLOUDFLARE_TOKEN" \
  --namespace=kube-system
```

![](/images/img_d012e00bd0dcad7a.png)

그리고 cloudflared용 deployment를 하나 정의해서 즉시 생성한다.  

```javascript
vim cloudflared.yaml

kubectl apply -f cloudflared.yaml
```

```javascript
apiVersion: apps/v1
kind: Deployment
metadata:
  name: cloudflared-deployment
  namespace: kube-system
spec:
  replicas: 2
  selector:
    matchLabels:
      app: cloudflared
  template:
    metadata:
      labels:
        app: cloudflared
    spec:
      containers:
      - name: cloudflared
        image: cloudflare/cloudflared:latest
        args:
        - tunnel
        - --no-autoupdate
        - --metrics
        - 0.0.0.0:2000 
        - run
        env:
        - name: TUNNEL_TOKEN
          valueFrom:
            secretKeyRef:
              name: cloudflared-token
              key: token
        livenessProbe:
          httpGet:
            path: /ready
            port: 2000
          initialDelaySeconds: 15
          periodSeconds: 10
```

## 터널 엔드포인트 등록하기

이제 만들어놓은 세팅을 기반으로 DNS 기반 엔드포인트를 열어보자.  
이번에 열어볼 것은 headlamp다. 지금은 내부 IP로만 접근이 되는데  

![](/images/img_cde09b0c794dfc45.png)

이걸 적당히 쿠버 내부 IP나 DNS로 등록해주면  

![](/images/img_8638121c5062fbfb.png)

바로 외부에서도 이렇게 접근이 가능해질 것이다.  

![](/images/img_63257ef092885168.png)
이게 꽤 편하다.  

이러면 Cloudflare를 거쳐서 쓰기 때문에 IP 기반 화이트리스트 처리나 이런저런 보안 설정도 손쉬운 편이다.
